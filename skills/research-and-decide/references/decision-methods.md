# 决策方法

先筛选硬性条件并综合证据，再选择合适的决策方法。

## 硬性条件筛选

比较评分前，先执行通过或不通过检查。常见硬性条件包括预算上限、适用地区、最低兼容要求、截止时间、安全条件和必需功能。

不能用其他指标的高分补偿一票否决项。记录每个被淘汰方案未通过的原因。

## 加权决策矩阵

当两个或更多可行方案需要在若干相互竞争的指标上比较时使用。

1. 定义彼此独立、与决定相关并且能够合理评分的指标。
2. 将必需条件与加权偏好分开。
3. 根据用户优先级分配权重，并归一化为 100%。
4. 评分前，定义每项指标中的 0 分、5 分和 10 分分别代表什么。
5. 使用同一尺度评价所有方案，并为重要评分提供证据。
6. 计算 `总分 = sum(归一化权重 × 评分)`。
7. 检查权重或评分的合理变化是否会改变排名。

避免重复计算。例如，“易用性”“培训时间”和“采用率”可能反映同一个底层因素。将其合并，或者说明它们为何彼此独立。

### 评分工具输入格式

```json
{
  "criteria": [
    {"name": "成本", "weight": 30},
    {"name": "质量", "weight": 45},
    {"name": "速度", "weight": 25}
  ],
  "options": [
    {"name": "方案 A", "scores": {"成本": 8, "质量": 9, "速度": 6}},
    {"name": "方案 B", "scores": {"成本": 6, "质量": 7, "速度": 9}}
  ]
}
```

权重可以使用比例或百分数，工具会自动归一化。评分必须在 0～10 之间。将输出视为决策支持，不要视为结论证明。

## 期望值分析

当各方案会产生互斥结果，并且能够估计结果概率和可比较后果时使用。

计算公式：

`方案期望值 = sum(结果概率 × 结果价值)`

确保结果集合覆盖所有可能性，而且彼此不重叠。使用基础概率、参照群体或透明假设估计概率。点估计会造成虚假精确时，改用范围。

对于一次性、不可逆、事关生存，或受流动性、安全、伦理和风险承受能力约束的决定，不要机械选择期望值最高的方案。纳入选择权价值、非金钱后果和下行风险集中程度。

## 情景分析

当概率不可靠，但可以描述若干连贯的未来状态时使用。

1. 找出最影响选择的两三个不确定因素。
2. 构建少量彼此不同且合理的情景。
3. 在每种情景下评价所有方案。
4. 识别稳健方案、脆弱方案、早期信号和备用行动。

如果表面上的领先方案依赖单一且狭窄的预测，优先考虑在不同情景下更稳健的次优方案。

## 可逆试验与信息价值

当不确定性很重要，而且可以在全面投入前先学习时使用。

比较：

- 解决不确定性可能带来的收益；
- 获取信息的成本和延迟；
- 立即行动的可逆程度；
- 等待造成的成本；
- 小范围试验能否揭示决定性信号。

提出试验时，明确周期、成功指标、停止条件和下一次决策日期。不要只说“继续研究”，而要说明需要解决哪个不确定因素，以及不同结果会怎样改变行动。

## 解释敏感性

- **稳健**：合理变化不会改变首选方案。
- **有条件成立**：首选方案取决于明确的优先级或情景。
- **脆弱**：很小的合理变化就会逆转结果。
- **无法判断**：现有证据不能区分领先方案。

对于脆弱或无法判断的结果，建议先协调利益相关者、进行可逆试验、谈判或定向收集数据，不要假装存在明确赢家。
